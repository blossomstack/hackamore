Glossary

The vocabulary

service / target
One configured upstream instance. A rule's targets name these (empty = any service).
verb
The literal thing the request states: the HTTP method (GET / POST / PUT / PATCH / DELETE, …) or a named action (e.g. ec2:RunInstances). Empty in a rule = any verb.
resource
What's acted on: a path (e.g. repos/octocat/hello/pulls). Rules match paths with globs.
glob
* matches one path segment, ** the rest. e.g. repos/*/*/pulls.
condition
An extra constraint on a request field — equals, one-of, or exists. Field names come from a service's imported model.
effect
Allow or Deny. An explicit Deny always wins over an Allow.
default-deny
If no rule matches, the request is denied. There is no bypass.
credential id
A vault key naming the real secret a service injects upstream. The agent never sees it; neither does this UI.
model
A service's imported API description (OpenAPI/Smithy) — operations, selectors (method + route, or named action), fields. The source of truth lint and discovery work from.
Runtime

Registered services

Services added at runtime from an OpenAPI or Smithy description. The description generates the catalog; hackamore enforces and proxies to it.
